# Producto mínimo viable (MVP)

> Dueño: Felipe Tapia (CEO & PM). Actualizar cada vez que una entrevista o piloto cambie lo que sabemos.
> Todo lo que dice **hipótesis** todavía NO está comprobado.

## 1. Problema (hipótesis)

Las pequeñas y medianas empresas en Ecuador tienen obligaciones de Seguridad y Salud en el Trabajo (Reglamento de SST — Decreto Ejecutivo 255 de 2024 y normativa del Ministerio del Trabajo), pero:

- no saben con claridad **cuáles les aplican** según su tamaño y actividad,
- no tienen un técnico de SST de planta,
- se enteran de lo que les falta cuando llega una inspección o una multa.

**Por validar en entrevistas:** ¿es este un dolor real?, ¿quién en la empresa lo siente (gerente, RR.HH., contador)?, ¿cuánto pagan hoy por resolverlo?

## 2. Cliente objetivo inicial (hipótesis)

- Empresas de **10 a 49 trabajadores** en Quito (umbral en el que, según el MDT, se exige delegado de SST).
- Sectores con riesgo visible: alimentos, comercio con bodega, talleres, construcción pequeña.
- Quien decide y paga: gerente-dueño o responsable de RR.HH.

## 3. Qué vendemos primero

**Diagnóstico de cumplimiento SST**:

1. Reunión / formulario con la empresa (tamaño, actividad, sedes, puestos).
2. Revisión contra una lista de requisitos **verificados** (tabla `requisitos`).
3. Informe: % de cumplimiento, qué falta, evidencia esperada y **plan de acción** priorizado.
4. Seguimiento opcional mensual del plan de acción.

Lo que **NO** hacemos (y lo decimos al cliente): no firmamos como técnico de SST, no reemplazamos al médico ocupacional, no damos asesoría legal. Para eso trabajamos con un profesional aliado.

## 4. Alcance del MVP

| Entra | No entra (todavía) |
|---|---|
| Registro de la empresa, sedes y puestos | App móvil |
| Lista de requisitos con fuente verificada | Muñecos educativos, experiencia tipo Tamagotchi |
| Diagnóstico y % de cumplimiento | Gestión de seguros médicos |
| Plan de acción con responsables y fechas | Ficha médica / datos de salud |
| Matriz de riesgos básica por puesto | Integración con la plataforma SUT del MDT |
| Registro de capacitaciones | Facturación automática |
| Consultas al agente con revisión humana | |

**Se puede vender antes de tener interfaz**: el primer diagnóstico se puede hacer con la base de datos + un informe en documento. Si nadie paga por el diagnóstico hecho a mano, una app no lo va a arreglar.

## 5. Métricas (del Mapa de Gaps)

| Indicador | Meta inicial |
|---|---|
| Entrevistas a potenciales clientes | 5–10 |
| Problema prioritario identificado | 1 |
| Requisitos verificados por un profesional SST | 10–15 |
| Organizaciones contactadas para piloto | 3–5 |
| Diagnósticos piloto realizados | 1 |
| Primer cliente que paga | 1 |
